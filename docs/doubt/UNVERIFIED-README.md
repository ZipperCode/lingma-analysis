# 怀疑区 — 未验证的推测与假设

## 什么是怀疑区

这里的文档包含 **IDA 静态分析推导出的结论**，这些结论 **从未被 Frida 运行时捕获验证**。主要问题包括：

1. Frida Hook 安装成功但目标函数**从未被触发**（见 `frida-verification-summary.md`）
2. 关键函数的**参数顺序**和**字段名**存在互相矛盾的版本
3. 部分端点始终返回 403/404，无法实际验证请求构造是否正确

## 如何阅读这些文档

- **当作假设而非结论**
- 如果某个推测后来被 Frida 运行时验证，可以将文档提升回 `docs/topics/`
- 参见 `CONTRADICTIONS.md` 了解跨文档矛盾

## 提升条件

要将文档移出怀疑区，需要满足以下之一：
- Frida Hook 成功触发并捕获到实际参数值
- 通过活跃端点（非 403/404）验证请求构造
- 通过其他独立方法（如流量对比）确认结论
