# tools 根目录历史报告副本

更新时间：2026-05-04

这个目录保存从 `tools/` 根目录移出的历史 Markdown 工作副本。

## 为什么单独保留

- `docs/tools-archive/` 中已有整理版工具阶段报告。
- `tools/` 根目录同名 Markdown 和整理版内容不完全一致。
- 为避免覆盖整理版，同时清理 `tools/` 根目录，所以把这些工作副本集中到本目录。

## 使用规则

- 优先阅读 `docs/README.md` 指向的当前主文档。
- 如需工具阶段证据，先看 `docs/tools-archive/` 根层整理版。
- 本目录只用于追溯当时 `tools/` 根目录留下的原始工作副本。
